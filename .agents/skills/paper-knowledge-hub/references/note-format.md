# 论文笔记结构

已对齐 main 的 paper-note 内容组织（2026-09-23），持久化位置适配本项目：只写 paper.note，不创建 main 文献条目，也不调用 Notion。阅读状态在本项目 status 维护。

完整笔记按八章组织：论文概览、研究背景与问题定义、相关工作、方法、实验设计、实验结果与分析、局限性与讨论、附录。概览先解释中心变化与代表性效果；方法沿输入、表示、变换、输出与学习信号重建；结果保留条件、反例与不可比项。

附录根据实际来源保留资源与复核条件、论证措辞以及 Abstract / Introduction / Conclusion 的完整双语原文；未读或无来源不得补造。局部补充保留原内容与稳定引用，不把已有短笔记强制扩写成未核验精读。

公式用 `$...$` 和 `$$`。代码使用 fenced code block，图像保留来源与图注；远程插图在网页由用户点击加载。表格保留单位、指标和比较条件。`claimEvidence` 引用当前论文 evidence ID；PDF `pageIndex` 是文件页序。
