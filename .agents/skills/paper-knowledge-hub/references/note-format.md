# 网页论文笔记契约

本项目只维护 `paper.note` 一份正文；不创建 main 文献条目，也不调用 Notion。这里的网页模板按本站功能分工组织，不要求沿用其他仓库的八章模板。

执行契约是 [note-template.mjs](../../../../src/lib/note-template.mjs)：浏览器编辑器和 `ai:prepare` 导入同一模块。`NOTE_SECTIONS` 定义章节及职责，`createNoteTemplate()` 生成空白模板。`templates/paper-note.md` 与 `templates/paper-recommended.json` 是它的可下载副本，测试检查一致性。

| 内容                                       | 维护位置         | 正文的任务                       |
| ------------------------------------------ | ---------------- | -------------------------------- |
| 题名、作者、年份、版本、来源               | 书目字段         | 不再抄一张基础信息卡             |
| 问题、方法、数据、评测、结论、局限的短概括 | 研究速览字段     | 解释推理和条件，不复制摘要表     |
| 主题、任务、方法、模型、数据分类           | topics / facets  | 在论述中按需链接，不重列分类清单 |
| 背景、机制、实验分析、讨论和材料           | note             | 持续维护的精读正文               |
| 私人研究判断和未公开构想                   | personalAnalysis | 与可公开正文分开                 |

新笔记使用五个 H2：

1. **背景与研究脉络**：前置知识、关键假设、已有路线瓶颈与近邻差异。
2. **方法与机制**：输入、表示、核心计算、输出、训练信号、推理流程与设计取舍。公式、流程图和代码对应只在帮助理解时加入。
3. **实验与结果分析**：按验证问题连接协议、基线、结果、消融和解释；保留单位、条件、反例及不可比项。
4. **讨论与启发**：作者局限、整理者解释和未验证推测分开；说明外推条件与替代解释。私人构想另存。
5. **资源与复核**：实际阅读范围、未解决疑点、图表/章节定位、官方资源与代码观察。双语摘录或更长原文材料按已有需求保留，不强制粘贴全文。

这是一份写作起点，不是完成度检查表。空模板不代表读过论文；缺少材料时保留未知。旧八章和其他已有 Markdown 照常阅读、导出；局部更新保留原结构和未修改内容，只有明确的重构任务才重新组织。

公式使用 `$...$` 和 `$$`，代码使用 fenced block。图像保留来源和图注，远程图片由用户点击加载。关键数字在实际论述处链接到原文章节、图表或 PDF 页，不用在正文重复 `ev-*` 清单；`claimEvidence` 在结构化字段中引用本论文已有 evidence ID。PDF `pageIndex` 是一基文件页序，不能猜测印刷页码。来源检查、引用数量和模板章节数都不能替代精读或实验复现。
