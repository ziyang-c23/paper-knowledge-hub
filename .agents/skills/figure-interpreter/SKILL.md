# 图表解释

保留原图、图号、PDF 页码和原图注；网页解释层只重绘结构和交互，不改变数值、方向或拓扑。为每个区域绑定正文章节和来源定位，写清该图回答的问题及不能回答的问题。方法图可转步骤流；结果图保留实验条件、误差与缺失值。

来源未实际读取、图片质量不足或图注无法确认时，停在待核验，不补造节点。解释动画是整理者重绘时明确标注，不是机器人运行视频。
