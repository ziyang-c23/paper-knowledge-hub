# 论文—代码对照

记录论文模块、仓库 URL、固定 commit、path、symbol、配置、代码版本与论文版本关系。指出代码默认参数是否等于论文实验配置；记录实现中论文未展开的工程细节。只能写静态代码观察，除非存在实际运行记录，否则不写 runtime-result。

当前主分支、README 或模型卡不能替代正文实验；未运行的行为不得写成复现。输出进入私有来源/草稿，公开前逐项检查 commit、许可和敏感路径。
