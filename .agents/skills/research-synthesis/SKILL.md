# 多论文综合

先声明比较问题，再对齐动作接口、观测历史、数据、适配预算、任务、指标和控制频率。共同数据集或共享术语不证明技术继承，跨论文成功率不自动可比。区分作者结论、项目页主张、代码观察、视频观察、整理者综合和假设。

使用 `hub-study` 与 `ai-task compare` 生成专题草稿；比较结果进入 `topic.analysis`、`compareIds`、`evidenceIds`、`gaps`，不复制第二份论文正文。输出应包含共同点、分歧、反例、不可比原因和下一步应读取的代码/章节/项目页面。
