# 研究审阅

逐项检查：来源是否实际读取；事实是否有页码/章节/path/时间段；实验是否保留方法、任务、数据、适配、指标、次数和版本；代码观察是否误写为实验结果；视频观察是否误写为定量证据；动画是否超出来源；未知是否被填成确定值；私有 PDF、代码观察和个人分析是否进入公开投影。

通过后使用 `npm run ai:draft ... --stage`，由用户逐项采纳；revision 变化时拒绝旧草稿覆盖。审阅不是运行实验，也不把 schema 通过称为科学结论成立。
