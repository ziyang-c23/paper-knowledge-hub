## 两轮迭代记录

第一轮实际实现：保留 React/Vite/Node/JSON；新增本地主库、编辑与恢复、公开字段允许规则、PDF 逐页索引、三策略检索。运行原始 V1 基线、核心单测和首轮 6 项浏览器任务。浏览器复审查出备份 ID 契约、cites 枚举和保存提示生命周期；检索首轮不存在词误命中，记录原始失败。

第二轮依据失败修复：补齐 cites；修正恢复菜单；JSON 导入按字段合并并拒绝错误类型；旧版本冲突可导出/重读/合并；关联编辑离开提醒；本地模型 POST 加 token、模型页限定公开记录；归档代表证据排除；双维分类使用交集；PDF 原生 iframe 在实际内嵌浏览器空白，改为 PDF.js canvas 并修复 worker MIME。来源复核移除了不能支持整个比较字段的“相关证据”绑定，不用引用存在冒充支持成立。

## 任务对照（公开样例 + 明确标记的合成边界任务）

| 任务 | V1 实测流程 / 缺口 | V2 交付与验收 |
|---|---|---|
| A 纳入与编辑 | 网页填写 → 导出 JSON → 外部审查 → CLI 导入 → 构建；不能编辑私有主库 | 一次初始化后，网页填基本书目 → 保存草稿 → 正式入库；POST、文件读回、刷新及重启测试通过；无日常 CLI 切换 |
| B 更新分类/关系 | 手工改公开 JSON 并重建 | 编辑主库后详情/专题/比较/图谱/检索读取同一版本；cites 仅引用；双维筛选交集及刷新保留通过 |
| C 问题检索 | 笔记字段 AND、已审核图扩展 | 可区分元数据/笔记/证据/逐页 PDF、词法排序/别名；显示覆盖、未解析论文、匹配词、直接/扩展原因 |
| D 比较与导出 | 比较表与一般来源链接 | 字段依据可维护；导出未知项、条件、证据状态/位置，专题可继续比较；本地 Awesome 待审条目不修改目标 taxonomy |
| E 原文定位 | 论文/HTML 链接，没有本地文件页 | 两份 54 页 PDF；原件与逐页文本对照；页面渲染像素与跳页通过；字段支持范围另做来源复核 |
| F 缺乏资料 | 字面无命中空状态 | 不存在串不生成答案；部分词命中明确不等于问题得到回答。未实现自然语言充分性裁决 |
| G 私有/归档/恢复 | private 只能留在文件，不能工作台浏览 | 本地可用；公开投影不含 private/draft/archived 和私有字段，包不回拷旧 seed；归档从默认查询/图/统计排除，恢复后生效 |
| H 模型关闭 | 静态检索可用 | 全部本地维护、PDF、浏览与检索不依赖模型；真实浏览器覆盖；模型协议仅 mock |

操作步骤是实现路径对照，没有招募真人计时，也没有宣称固定百分比效率收益。首次安装仍需终端；公开构建仍需 npm run build。题名、来源和支持范围必须由使用者审查，自动保存不减少该审核责任。
