# V2 独立审查与浏览器验收

审查目标是发现不成立的交付主张，不以功能数量判断成功。审查者仅拥有 V2 浏览器测试与本文档；实现修复由对应代码维护者完成。

## 方法与隔离

`playwright.v2.config.js` 启动真实 Chromium，使用 `createLocalServer` 在 `127.0.0.1:4177` 提供构建后的 `dist`。测试将公开示例复制到系统临时目录，再显式初始化为私有研究库；每项测试恢复干净主库。未修改日常使用的 `private/workspace.json`，未调用模型、推送或部署。

运行：

```sh
npm run build
npx playwright test --config playwright.v2.config.js
```

浏览器截图、错误轨迹与报告默认位于忽略目录 `tmp/v2-review/`。其中有明确标记的合成测试文字，只用于持久化、冲突和界面边界测试，不支持任何学术检索效果结论。

## 第一轮发现

| 发现 | 证据 | 影响与处理 |
|---|---|---|
| 备份列表字段契约不一致 | API 返回 `backupId`，UI 原先只读 `id/name` | 恢复点无法正确选择；报告实现者并增加完整 UI 恢复回归 |
| 引用关系可选但 schema 拒绝 | 浏览器选择 `cites` 后 POST `/api/records` 返回 422，错误为 relation type 枚举不接受 | 属于真实不可用入口；报告后端维护者补齐枚举 |
| 新论文保存后状态条消失 | 首次保存真实返回 200，主库出现记录，但 `/edit/new` 切换稳定 ID 路由导致组件重建、成功框清空 | 数据未丢失；不应将缺少成功框误报为写入失败。测试改查真实响应、未保存状态与文件读回；建议持久化保存提示 |
| 关联编辑缺少未保存提醒 | 代码审查：对象类型/对象/维护 tab 切换直接更换记录 | 容易丢失未落盘编辑；报告实现者 |
| 检索笔记片段显示 Markdown 原码 | 已查看实际 Chromium 桌面截图，片段内可见 `##` 和链接源码 | 可读性不足；建议渲染或转为干净文本。不是学术相关性缺陷 |

第一轮运行 6 项：3 项通过，3 项失败。其中两项失败是测试错误地依赖新记录路由切换后持续存在的成功框；另一项是实际 `cites` schema 拒绝。已通过的真实流程包括两个标签页的冲突保护与未保存修改导出、对比材料来源导出、无模型时本地查询、5 个窄屏路由无横向溢出。

## 最终复测

第二轮核心 8 项真实浏览器流程全部通过，完整运行耗时 13.3 秒；这是自动脚本耗时，不是真人效率。随后添加实际 PDF 渲染与多维筛选专项：首次 PDF 像素检查真实失败，错误为动态 worker 的 `.mjs` 被服务为错误 MIME。修复 MIME 并重启服务后，PDF 与双维度筛选 **2/2 通过（6.9 秒）**。不是只检查 canvas 标签：测试采样像素差异、切换文件页序、确认提取文本改变，并等待渲染完成后截图。

实现者还补充了关联编辑的离开/切换提醒、显式编辑重读、已落盘记录提示。未保存草稿导出与重读已在浏览器中复核；没有将局部代码审查等同于全部交互路径验证。

## 判断范围

- 浏览器流程与文件读回能证明被测试的数据操作正确，不能证明研究工作效率提升的幅度。
- 原文定位、引文支持范围和真实 PDF 提取质量由全文专项验证记录负责；点击一篇论文不能证明其支持某个结论。
- 未测试真实模型服务，未用模拟回答宣称真实模型成功。
- 小型公开示例和合成边界测试不能外推到所有论文、长时间日常使用或大规模文献库。
