# 当前边界

- 已实现本机完整私有库浏览、文件持久编辑、逐页 PDF 检索和恢复；不提供云同步、多人协作、远程认证、GitHub 在线写回或移动设备跨机同步。
- 当前本机保留 9 篇真实示例和 2 份解析 PDF，阅读深度不同，不能代表领域覆盖。私有库不随源码包分发；当前公开投影为空，包内初始化得到空库。
- JSON/Markdown 支持标准字段导入与编辑；不是 Notion ZIP、Zotero、BibTeX、任意 YAML 或旧库自动迁移工具。author 可暂空，其他最小书目字段仍需满足 schema。
- 增强检索是词法排序与已审核图扩展，不是 embedding、自然语言理解、自动实体抽取或完整 GraphRAG。固定小样本评估只反映这批问题和原件，见 [检索评估](retrieval-evaluation.md)。命中数量不是准确率。
- PDF 提取没有 OCR；扫描页可能无文字。双栏顺序、公式、表格、图片和精确版面需看原件；文件页序不是印刷页码。解析成功不等于全文已人工阅读或证据已 verified。
- 模型 HTTP 适配器及明确标记的 mock 测试已实现，但没有真实提供方调用验证。引用 ID 检查不能证明答案的事实蕴含关系；私有全文不会自动发送给模型。
- 单文件主库与本地锁适合单用户使用；没有万篇容量、分布式一致性或跨文件数据库事务保证。自动历史只保留最近 100 个主库快照，不含 PDF 原件；完整恢复仍需备份。异常中断的锁需人工核实后清理；完整流程见 [恢复手册](v2-storage.md)。
- 比较保留各论文评测条件和未知字段，不统一数值排名。引用复制是可读书目信息，非期刊定制格式。新增字段需同步 schema/校验/UI。
- 本地页面载入完整库和解析文本，未实现大型语料分页后端或按页按需装载。Windows 尚未实机验证；测试依赖本机端口与浏览器运行环境。
- Markdown 支持表格、公式和代码，不执行原始 HTML；外部图片不自动加载。可访问性和窄屏检查不等于完整 WCAG 认证或全屏幕阅读器覆盖。
- 浏览器下载本地笔记或专题可能含私有材料；CLI export 和源码包只含公开子集；study:export 显式导出本地研究材料。public/private 过滤不能识别你主动写入 public note 的秘密。
- 本轮没有远程仓库创建、commit/push、公网部署或真实模型调用。本机网页、源码 ZIP、线上站点和模型实测分别验收；历史版本测试数字不代表当前结果。

- 网页草稿可导入、编辑、校验、应用和回看；AI 内容由宿主 Agent 生成，未配置网页模型时不会自动生成笔记。待审草稿不在主库备份内，需单独导出。
