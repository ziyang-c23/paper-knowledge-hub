# V2 本地、公开与模型边界

完整权威主库存放在 ignored `private/workspace.json`，PDF 原件与逐页文本在 `private/documents/`。本地服务可以读取这些内容并送到本机浏览器以支持工作；公开静态站点只包含显式过滤后的投影。不要为了本机显示把 private 改成 public。

初始化默认所有对象 private。每次编辑公开记录需要重新审查并显式允许公开；否则编辑器按 private 保存。论文还必须 active 才能进入公开构建，归档不删除主库。personalAnalysis/privateNotes 始终排除，PDF、全文索引及文档定位字段不自动公开。note 和结构化字段可能公开，需自行审查其文字。

过滤流程：完整 schema 与引用校验 → 按对象允许字段 → public/active 实体 → 证据所属论文 → 关系两端与全部证据 → 分类及专题引用过滤。图、搜索、统计和 CLI 导出使用一致的作用域。初始化后构建、导出和源码包使用当前权威库，不从旧模板恢复被你取消公开的记录。

源码 ZIP 重建 content 的公开子集，排除 private、.env、Git 历史、安装依赖、生成物、临时输出和本地模式截图。它不备份完整个人库。浏览器“导出当前修改/笔记/专题”是本地下载，可包含私有文字；下载不自动上传，但后续分享由你决定。

本地 API 只监听 loopback，拒绝不合规 Host/Origin/Fetch-Site；变更请求要求启动期间随机 token，不启用 CORS，私有响应 no-store，拒绝私有路径符号链接。没有公网身份权限系统，不应通过改监听地址将它当多人服务。

可选模型只接收明确 consent 请求，服务端重新读取并检索公开投影，发送问题和最多 8 条 verified source/note 证据。私有 personalAnalysis、证据和 PDF 不会进入模型上下文；查询本身仍会发送，因此不要在问题里写不愿交给提供方的私密内容。密钥仅放项目 .env，不进入 Vite 构建、浏览器或 localStorage。configured 只表示配置完整，未作真实连通验证。

Markdown 原始 HTML 不执行，外部图片不自动加载；主动点击外链或使用官方 arXiv 下载仍访问外网。论文文本中的指令不会作为程序命令执行。测试使用明确标记的合成私有内容和 mock，不包含真实密钥。

Git 忽略不是加密；完整备份应存于你控制的私有介质。已写进公开 Git 历史的文字不会随删除文件自动消失。首次推送/发布要审查实际文件及历史；当前项目未替用户进行远程发布。
